# COFFEE-SHOP-SALES-PERFORMANCE-ANALYSIS
BREWING INSIGHTS DASHBOARD
The project presents an interactive Microsoft Excel dashboard developed to analyze coffee shop sales performance and identify key business trends.The dashboard provides insights into total sales, total orders, quantity sold, product categories, top-performing products, monthly sales trends, peak sales hours, and store-level performance. Interactive filters allow users to explore the data by month, store location, and product category.

Key Features
📊 Sales performance KPIs
📈 Monthly sales trend analysis
☕ Sales by product category
🏆 Top 3 products by sales
🕐 Peak sales hour analysis
📍 Sales performance by store location
🔎 Interactive Excel filters
📋 Business-focused dashboard

Tools Used
Microsoft Excel
Pivot Tables
Charts & Visualizations
Data Analysis
KPI Analysis
Interactive Dashboard

Objective
To transform raw coffee shop sales data into meaningful insights that help understand sales trends, product performance, peak business hours, and store-level performance.

Excel Dashboard | Data Analysis | Sales Analytics | Business Intelligence
